Pydantic AI

A Python agent framework built by the Pydantic team. Bringing the FastAPI experience to GenAI app and agent development.

16.5k+ GitHub Stars v1.85.1 — April 2026

What is Pydantic AI?

Pydantic AI is a Python framework for building agents and generative AI applications with type safety built in from the ground up. It was created by the same team behind Pydantic and FastAPI, two of the most widely used libraries in the Python ecosystem.

The core idea: just as FastAPI revolutionized web development with automatic validation and type hints, Pydantic AI does the same for AI agents — structured, validated, and predictable outputs.

Unlike other frameworks that treat LLM responses as unstructured text, Pydantic AI guarantees that the output matches exactly the schema you define. If the LLM fails to produce valid output, the framework automatically prompts it to try again.

Why it matters

Pydantic Validation is already the validation layer behind: OpenAI SDK, Google ADK, Anthropic SDK, LangChain, LlamaIndex, CrewAI, AutoGPT, and many more. Pydantic AI goes straight to the source.

Core Features

Type-Safe by Design

Every parameter, return value, and LLM output is automatically validated. Errors are caught at write-time, not runtime.

Model-Agnostic

OpenAI, Anthropic, Gemini, DeepSeek, Grok, Mistral, Ollama, Bedrock, Groq, and more. Swap models without changing code.

Dependency Injection

Pass DB connections, API keys, and custom logic in a type-safe way. Testing and mocking becomes trivial.

Native Streaming

Structured real-time output with Server-Sent Events. Continuous validation as data is generated.

Tools & Capabilities

Register functions as tools with decorators. Composable capabilities: web search, thinking, MCP.

Durable Execution

Agents that survive API failures, restarts, and long-running async workflows with production-grade reliability.

Graph Support

Define complex multi-step workflows as graphs with type hints. Avoids spaghetti code in branching logic.

Observability

Native integration with Pydantic Logfire (OpenTelemetry). Real-time debugging, traces, and cost tracking.

Code Examples

1. Minimal Agent

from pydantic_ai import Agent

agent = Agent(
    'anthropic:claude-sonnet-4-6',
    instructions='Be concise, reply with one sentence.',
)

result = agent.run_sync('Where does "hello world" come from?')
print(result.output)
# → The first known use of "hello, world" was in a 1974
#   textbook about the C programming language.

2. Agent with Tools & Dependency Injection

from dataclasses import dataclass
from pydantic_ai import Agent, RunContext

@dataclass
class DatabaseConn:
    # Simulated DB connection
    async def customer_name(self, *, id: int) -> str:
        ...

@dataclass
class SupportDependencies:
    customer_id: int
    db: DatabaseConn

support_agent = Agent(
    'openai:gpt-4o',
    deps_type=SupportDependencies,
    instructions='You are a bank support agent.',
)

@support_agent.tool
async def customer_name(ctx: RunContext[SupportDependencies]) -> str:
    name = await ctx.deps.db.customer_name(id=ctx.deps.customer_id)
    return f"The customer's name is {name!r}"

result = await support_agent.run(
    'What is my balance?',
    deps=SupportDependencies(customer_id=123, db=db),
)

3. Agent with Capabilities (Thinking + Web Search)

from pydantic_ai import Agent
from pydantic_ai.capabilities import Thinking, WebSearch

agent = Agent(
    'anthropic:claude-sonnet-4-6',
    instructions='Be concise, reply with one sentence.',
    capabilities=[Thinking(), WebSearch()],
)

result = agent.run_sync(
    'What was the mass of the largest meteorite found this year?'
)
print(result.output)

4. Structured Output with Pydantic Model

from pydantic import BaseModel
from pydantic_ai import Agent

class CityLocation(BaseModel):
    city: str
    country: str
    continent: str

agent = Agent(
    'gemini-2.0-flash',
    result_type=CityLocation,
    instructions='Return city info.',
)

result = agent.run_sync('Where is the Eiffel Tower?')
print(result.output)
# → CityLocation(city='Paris', country='France', continent='Europe')

Real-World Use Cases

Customer Support

RAG & Search

Agents with integrated web search and retrieval. Structured output ensures consistent format.

IT Automation

Data Analysis

Agents that query databases and generate structured reports. Type safety prevents broken outputs.

Document Processing

Structured extraction from documents. Pydantic models guarantee required fields are present.

Integrations & Ecosystem

MCP (Model Context Protocol)

Native integration to connect agents with external tools and data via MCP servers.

A2A (Agent-to-Agent)

Inter-agent communication using Google's Agent2Agent protocol.

Pydantic Logfire

Full observability: traces, real-time debugging, cost tracking, performance monitoring. Built on OpenTelemetry.

Pydantic Evals

Evaluation system for measuring agent accuracy and performance. Integrated with Logfire for continuous monitoring.

Agent Spec (YAML/JSON)

Define agents entirely in YAML or JSON — no code required. Useful for declarative configuration.

When to Use Pydantic AI

✅ Great for:

  • Production applications that need reliable, validated outputs
  • Agents with complex tools and external data access
  • Multi-step workflows with conditional logic
  • Teams that value type safety and robust testing
  • Systems requiring observability and cost tracking
  • Projects already using Pydantic/FastAPI in their stack

⚠️ Maybe not for:

  • Quick prototypes where validation doesn't matter
  • Projects in other languages (Python-only)
  • Simple "prompt + response" cases without tools

Quick Start

# Install
pip install pydantic-ai

# With all provider extras
pip install pydantic-ai[all-extras]

# Or with uv
uv add pydantic-ai
# Required environment variables
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GOOGLE_API_KEY="..."

# Ready! Create your first agent
from pydantic_ai import Agent

agent = Agent('openai:gpt-4o')
result = agent.run_sync('Hello!')
print(result.output)
