¿Qué es Pydantic AI?

Pydantic AI es un framework de Python para construir agentes y aplicaciones de IA generativa con tipo seguro (type-safe) desde la base. Fue creado por el mismo equipo detrás de Pydantic y FastAPI, dos de las librerías más usadas en el ecosistema Python.

La idea central: así como FastAPI revolucionó el desarrollo web con validación automática y type hints, Pydantic AI hace lo mismo para agentes de IA — outputs estructurados, validados y predecibles.

A diferencia de otros frameworks que tratan las respuestas de LLMs como texto no estructurado, Pydantic AI garantiza que el output cumple exactamente con el schema que definiste. Si el LLM falla, el framework automáticamente le pide que corrija.

¿Por qué importa?

Pydantic Validation ya es la capa de validación detrás de: OpenAI SDK, Google ADK, Anthropic SDK, LangChain, LlamaIndex, CrewAI, AutoGPT, y muchos más. Pydantic AI va directo a la fuente.

Características Principales

Type-Safe por diseño

Cada parámetro, retorno y output de LLM es validado automáticamente. Errores se detectan al escribir, no al ejecutar.

Model-Agnostic

OpenAI, Anthropic, Gemini, DeepSeek, Grok, Mistral, Ollama, Bedrock, Groq, y más. Cambia de modelo sin cambiar código.

Dependency Injection

Pasa DB connections, API keys y lógica custom de forma type-safe. Testing y mocking trivial.

Streaming nativo

Output estructurado en tiempo real con Server-Sent Events. Validación continua mientras se genera.

Tools & Capabilities

Registra funciones como tools con decoradores. Capabilities componibles: web search, thinking, MCP.

Durable Execution

Agentes que sobreviven fallos de API, restarts y workflows largos asíncronos.

Graph Support

Define workflows complejos como grafos con type hints. Evita spaghetti code en multi-step.

Observabilidad

Integración nativa con Pydantic Logfire (OpenTelemetry). Debug, traces, cost tracking en tiempo real.

Ejemplos de Código

1. Agente mínimo

from pydantic_ai import Agent

agent = Agent(
    'anthropic:claude-sonnet-4-6',
    instructions='Be concise, reply with one sentence.',
)

result = agent.run_sync('Where does "hello world" come from?')
print(result.output)
# → The first known use of "hello, world" was in a 1974
#   textbook about the C programming language.

2. Agente con Tools y Dependency Injection

from dataclasses import dataclass
from pydantic_ai import Agent, RunContext

@dataclass
class DatabaseConn:
    # Simulated DB connection
    async def customer_name(self, *, id: int) -> str:
        ...

@dataclass
class SupportDependencies:
    customer_id: int
    db: DatabaseConn

support_agent = Agent(
    'openai:gpt-4o',
    deps_type=SupportDependencies,
    instructions='You are a bank support agent.',
)

@support_agent.tool
async def customer_name(ctx: RunContext[SupportDependencies]) -> str:
    name = await ctx.deps.db.customer_name(id=ctx.deps.customer_id)
    return f"The customer's name is {name!r}"

result = await support_agent.run(
    'What is my balance?',
    deps=SupportDependencies(customer_id=123, db=db),
)

3. Agente con Capabilities (Thinking + Web Search)

from pydantic_ai import Agent
from pydantic_ai.capabilities import Thinking, WebSearch

agent = Agent(
    'anthropic:claude-sonnet-4-6',
    instructions='Be concise, reply with one sentence.',
    capabilities=[Thinking(), WebSearch()],
)

result = agent.run_sync(
    'What was the mass of the largest meteorite found this year?'
)
print(result.output)

4. Output estructurado con Pydantic Model

from pydantic import BaseModel
from pydantic_ai import Agent

class CityLocation(BaseModel):
    city: str
    country: str
    continent: str

agent = Agent(
    'gemini-2.0-flash',
    result_type=CityLocation,
    instructions='Return city info.',
)

result = agent.run_sync('Where is the Eiffel Tower?')
print(result.output)
# → CityLocation(city='Paris', country='France', continent='Europe')

Casos de Uso Reales

Customer Support

Agentes de soporte con acceso a DB, CRM y herramientas. DI permite testing fácil con datos mock.

RAG & Búsqueda

Agentes con web search integrado y retrieval. Output estructurado garantiza formato consistente.

Automatización IT

Workflows multi-paso (onboarding, approvals). Graph support para flujos complejos con branches.

Análisis de Datos

Agentes que consultan DBs, generan reports estructurados. Type safety evita outputs rotos.

Code Generation

Agentes que generan, validan y ejecutan código. Human-in-the-loop para operaciones sensibles.

Document Processing

Extracción estructurada de documentos. Pydantic models garantizan que los campos están presentes.

Integraciones y Ecosistema

MCP (Model Context Protocol)

Integración nativa para conectar agentes con herramientas y datos externos vía MCP servers.

A2A (Agent-to-Agent)

Comunicación entre agentes con el protocolo Agent2Agent de Google.

Pydantic Logfire

Observabilidad completa: traces, debugging en tiempo real, cost tracking, performance monitoring. Basado en OpenTelemetry.

Pydantic Evals

Sistema de evaluación para medir precisión y performance de agentes. Integrado con Logfire para monitoreo continuo.

Agent Spec (YAML/JSON)

Define agentes completamente en YAML o JSON — sin código. Útil para configuración declarativa.

¿Cuándo usar Pydantic AI?

✅ Ideal para:

  • Aplicaciones de producción que necesitan outputs confiables y validados
  • Agentes con tools complejas y acceso a datos externos
  • Workflows multi-paso con lógica condicional
  • Equipos que valoran type safety y testing robusto
  • Sistemas que necesitan observabilidad y cost tracking
  • Proyectos que ya usan Pydantic/FastAPI en su stack

⚠️ Quizás no para:

  • Prototipos rápidos donde la validación no importa
  • Proyectos en otros lenguajes (es Python-only)
  • Casos simples de "prompt + response" sin tools

Quick Start

# Instalar
pip install pydantic-ai

# Con extras (todos los providers)
pip install pydantic-ai[all-extras]

# O con uv
uv add pydantic-ai
# Variables de entorno necesarias
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GOOGLE_API_KEY="..."

# ¡Listo! Ya podés crear tu primer agente
from pydantic_ai import Agent

agent = Agent('openai:gpt-4o')
result = agent.run_sync('Hello!')
print(result.output)
